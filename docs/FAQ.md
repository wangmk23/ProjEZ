# 常见问题

### 为什么需要“扩展”，而不是 Windows 的“复制”？

Windows 复制模式让两块屏幕显示同一桌面。ProjEZ 在扩展屏上显示捕获结果，才能让观众画面冻结或变黑，同时主屏继续操作。开始前把操作屏设为主显示器，再在程序中选择不同的来源和观众屏幕。

### 画质能否与系统复制模式一致？

同分辨率下使用原尺寸复制，避免不必要缩放。不同分辨率仍需缩放：GPU 缩小时使用面积加权采样；兼容 GDI 模式使用自身的缩放路径。来源分辨率较低时，放大不能产生原本不存在的细节。投影仪的原生分辨率、缩放、对焦和输出模式也会影响清晰度，因此不保证与系统复制逐像素相同。

### 显示器是 144 Hz，为什么实际 FPS 较低？

显示器刷新率与软件捕获/绘制帧率是不同数值。软件帧率受分辨率、核显、驱动和窗口捕获方式影响。办公笔记本可手动选择 30 FPS；预览也可以切换节能模式。状态栏 FPS 不是投影仪物理刷新率。

### 快捷键如何设置？

点击快捷键框，直接按下组合键，再点击“保存快捷键”。Esc 取消录制。关闭旧版程序后再设置，避免两个实例抢占快捷键。冲突提示只能确认注册是否成功，不能可靠判断是哪一个其他软件占用。

### 应用窗口投影变黑？

窗口最小化、关闭、受保护内容或捕获 API/驱动限制可能使捕获不可用。恢复或重新选择窗口后再开始。程序不会为了继续显示而自动切换成整个桌面。

### 黑屏与停止有什么区别？

黑屏保留输出窗口，用纯黑遮住观众屏幕。停止会关闭输出窗口，观众可能看到扩展屏桌面。需要临时隐藏内容时请使用黑屏。

### 杀毒软件提醒怎么办？

当前程序没有代码签名。核对下载来源、版本和 SHA256，再通过安全软件的官方渠道申请复核。某个旧版本通过复核不代表新二进制一定通过。不要依据 README 关闭安全防护。

### 鼠标限制如何解除？

默认可把鼠标留在操作屏。按 Ctrl+Alt+F11 释放限制，或在投影控制中关闭限制。停止投影也会解除限制。
