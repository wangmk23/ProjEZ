# 隐私与本地数据

ProjEZ 的投影与预览在本机完成。当前源码没有遥测、账号登录、自动上传画面或自动更新功能；运行时不调用网络客户端。GitHub 下载、构建依赖和 README 徽章属于外部服务，不属于投影程序的数据传输。

## 本机配置

设置保存在 `%APPDATA%/ProjectorFreezer/config.ini`。若 APPDATA 不可用，使用当前目录中的 `ProjectorFreezer/config.ini`。

配置保存来源和目标屏幕标识、四组快捷键、鼠标显示、缩放、刷新策略、主题及其他界面偏好。当前选定应用窗口的标题和画面不写入配置文件。捕获画面在内存和图形资源中处理，不自动保存为图片或视频。

投影整个屏幕时，屏幕上的消息、通知和窗口也可能被观众看到。窗口模式仅捕获选定窗口；窗口捕获失败不会自动改为整个桌面。辅助隐私保护不能代替检查观众画面，也不能保证拦截所有通知。

## 提交问题前

- 截图只保留必要的程序界面；隐藏真实桌面、窗口标题、文件名、聊天、邮箱和设备序列号。
- 不提交 `config.ini`、本机日志、账户令牌或含个人目录的完整错误输出。
- 描述设备品牌、分辨率、Windows 版本和捕获方式即可；不要提供个人账号或完整设备实例路径。

本公开仓库从当前源码建立独立 Git 历史，不包含原开发目录的现场记录、配置备份、私人交接或旧 Git 提交。展示截图是无实际投影内容的测试界面。
