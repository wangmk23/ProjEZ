# 0.7.12

## 界面与交互优化

- **高级页卡片整合**：将“本地配置 → 打开配置目录”、“恢复默认设置 → 恢复默认设置”、“强制 GDI 兼容模式”统一为标准 72 DIP 设置卡片，操作按钮与开关内嵌在卡片右侧，标准窗口（1120×820）下无需滚动即可一屏完整展示。
- **窄窗口自适应布局**：下拉框与快捷键框在窄窗口（640–820 DIP）下自动收缩宽度，留出充足左侧文字与警告空间；投影控制页刷新按钮在窄窗口下紧凑排布，避免挤压右侧鼠标限制说明。
- **底栏悬停提示优化**：鼠标悬停在底栏“停止”或禁用按钮上时，提示信息仅覆盖中间状态区，始终保留左侧实时状态/计时与右侧实测 FPS。
- **快捷键框与搜索框细节**：修正四项快捷键录制框在卡片内的垂直居中对齐；标题栏搜索框右侧增加放大镜图标，并支持按 Esc 键一键清空搜索词并退回焦点。

## 性能与测试加固

- **待机 0% 定时器静默**：预览定时器仅在投影运行或存在挂起托盘恢复时激活，待机及停止后自动休眠，消除 30Hz 空转唤醒。
- **GDI 预览零内存分配**：复用固定容量双缓冲切片读取预览帧，消除每帧约 921 KB 的堆内存重复分配。
- **API 句柄与画刷预绑定**：将高频绘制与消息路径中的 Win32 / GDI / GDI+ / Shell 过程句柄及关闭按钮悬停画刷提升为全局常驻绑定。
- **验证边界**：源码/vet、全页面最小窗口（640×480）越界检查、五档 DPI 截图、ZIP 校验及最终 EXE 参与全套测试均通过。未改动投影捕获与缩放核心；真实双屏 Peek/捕获排除表现与目标 Win10 核显现场仍待实机确认。

本产品由 AI 编制，功能与改进方向来自使用者的需求、测试和反馈。
