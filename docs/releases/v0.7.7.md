# ProjEZ 0.7.7

四组全局快捷键支持直接按键录制。点击输入框后按组合键，Esc 取消，再保存。录制期间暂停本程序的快捷键，避免误触操作。

- 冻结：Ctrl+Alt+F8
- 恢复：Ctrl+Alt+F9
- 黑屏：Ctrl+Alt+F10
- 停止：Ctrl+Alt+F12
- 释放鼠标：Ctrl+Alt+F11（固定）

继承 GPU 缩小画面采样改进、整屏与应用窗口投影、观众预览和显示器型号识别。程序在 Windows 扩展模式下工作；停止会露出副屏桌面，需要遮住内容时请使用黑屏。

下载 `ProjEZ-0.7.7-windows-x64.zip` 后解压运行。Windows 10 1903+ / Windows 11 x64；普通核显支持情况取决于驱动和负载。性能或画质问题请描述来源/目标分辨率与 GPU/GDI 路径。

程序未签名。核对同版本 `SHA256SUMS.txt`；历史样本的安全复核结论不自动适用于新构建。源码测试和本机构建检查不能代替目标设备验收。
