# 0.7.9

## 修复

- 针对投影屏幕底部任务栏重复的问题，区分主控窗口与观众输出窗口的任务栏策略。
- 观众窗口不再设置禁止全屏识别的 NonRudeHWND，改用 Windows Shell 的全屏窗口标记；停止时解除标记。
- 主控窗口继续保留任务栏保护，不隐藏系统任务栏，不更改任务栏设置，不切换前台窗口，不裁掉来源画面中的任务栏。

## 验证范围

已通过原生 Windows Shell 接口与窗口属性检查、源码回归测试及构建。当前开发机仅单屏，无法重现双屏上的任务栏叠加，因此本版先作为预发布供现场验证，0.7.8 仍保留为正式版。

验证时，请退出旧 ProjEZ 后启动本版，分别检查实时、冻结、黑屏和停止状态：投影端不应出现原生副屏任务栏，主控屏任务栏仍应正常操作；停止后副屏恢复桌面。

本产品由 AI 编制，功能与改进方向来自使用者的需求、测试和反馈。
