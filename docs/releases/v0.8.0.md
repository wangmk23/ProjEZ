# 0.8.0

## 新增

- 方便框选演示画面。进入“投影控制 → 框选画面”，点击应用窗口、拖动框选区域，或按 Enter 选择整屏。Esc 取消。
- “图文图层”可叠加文字、PNG、JPEG，例如会议名称、主持人姓名或单位标志。
- 支持自定义字体、字号、颜色、粗体、斜体、位置、尺寸、不透明度、层级和保存前预览。
- GPU 和 GDI 合成均保留图层。观众预览及冻结使用合成画面，黑屏隐藏所有内容。

## 使用说明

选择来源屏幕、观众屏幕并做好图层后开始投影。编辑来源和图层需要先停止投影。自定义区域跟随屏幕坐标，画面内的窗口移动后不会跟随窗口，需追踪应用时用窗口投影。区域从当前会话选取，显示配置变化后需要重新框选。图层设置保存在本机，图片移动后需要重新选择。

本版为预发布，用于验证真实双屏和目标 Win10 设备。Windows 便携包解压后运行。正式演示前请检查观众预览。

本产品由 AI 编制，功能与改进方向来自使用者的需求、测试和反馈。
